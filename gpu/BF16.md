# BF16-weight kernels (M5)

Source `bf16.vx`; host wrappers `QuantKernels.bf16_matvec` / `bf16_matmul` in `quant_ops.py`;
tests in `test_quant_simt.py` (CPU SIMT, `bf16_*`) and `test_quant_hardware.py` (A100, skipped
without a GPU). Same conventions as [INT4.md](INT4.md).

## Layout and entries

Weights are raw bfloat16 bits stored as `uint16` (the top 16 bits of a binary32; wrapper dtype
`uint16`), row-major `[N, K]` or stacked `[E, N, K]`. Activations, accumulation and output are
float32. Block size is a multiple of 32, normally 128; one warp per output element.

| entry | computes | grid.x |
|---|---|---|
| `glm_vx_gpu_bf16_matvec(out, weight, x, N, K)` | `out[N]` | ceil(N / warps) |
| `glm_vx_gpu_bf16_matmul(out, weight, x, expert_ids, M, N, K, E)` | `out[M,N]` | ceil(N*M / warps) |

`E == 0` is the dense batched form (`expert_ids` not read; pass a null pointer). `E > 0` is the
grouped form: `expert_ids[M]` (int32) selects each row's expert, an id outside `[0, E)` writes zeros
to that row. Offsets are int64. K=0 writes zeros; M, N <= 0 write nothing. Lanes read adjacent
16-bit weights and add their products in column order, then a full-warp shuffle reduction, so
results differ from a sequential float32 sum only by summation order; the M=1 matmul equals the
matvec bit for bit (tested).

## Decode

`glm_vx_bf16_decode` builds the value from exact power-of-two products because the hand PTX
pipeline has no bit cast (`f32::from_bits` is rejected). It is exact for all 65536 encodings:
signed zero, subnormals, max finite, +/-inf and every NaN payload (tested exhaustively against
`glm_vx.quant.bf16_to_f32`). NaN weights give NaN outputs, inf weights give inf (NaN when
multiplied by 0), as in float32. It is the same arithmetic as `glm_vx_i4_bf16`.

## Not measured

No performance claim. Decoding costs integer/float ops per element and halves weight traffic
versus float32 only in principle; tune (e.g. a cheaper decode, vector loads, weight reuse across
the M rows) only after a measurement on hardware. Not validated on a GPU yet (offline).
